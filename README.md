# Exercícios e projetos da UTFPR

Acervo de estudos com exercícios de programação em C das disciplinas Fundamentos de Computação I e II e trabalhos em AutoCAD.

| Pasta | Conteúdo |
| --- | --- |
| [fundamentosComp1](fundamentosComp1/) | Exercícios em C organizados por aula e listas de revisão para provas. |
| [fundamentosComp2](fundamentosComp2/) | Exercícios sobre estruturas, uniões, funções e passagem de parâmetros. |
| [autodesk](autodesk/) | Trabalhos de desenho técnico em formato DWG. |

Os exercícios em C são independentes. Abra o arquivo-fonte do exercício desejado e compile com seu compilador C. Se estiver usando GCC, por exemplo:

```sh
gcc fundamentosComp1/aula10/ex1.c -o ex1
```
